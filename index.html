nixos-restic-backup

A personal, single-user backup utility.

nixos-restic-backup is a private command-line tool that backs up the owner's own computers to the owner's own Google Drive. It runs locally on the owner's machines. There is no server, no account system, and no third-party service involved.

What it does

  • Reads the owner's local files and uploads an encrypted backup archive to Google Drive.
  • Uses Google Drive's drive.file scope, which grants access only to files and folders this application itself creates. It cannot see, read, modify, or delete any other file in the owner's Drive.
  • Stores no data anywhere except the owner's own machines and the owner's own Drive.

Who uses it

Exactly one person: the owner of the Google account that authorizes it. The application is not distributed, has no other users, and collects nothing about anyone else.
