Privacy Policy

nixos-restic-backup · a personal, single-user backup utility
Last updated: 2026-11-18

This policy describes how nixos-restic-backup ("the application") handles data when the owner authorizes it to access their Google Drive account.

1. Who operates this application

The application is operated by a single individual for their own personal use, on their own computers. It is not offered as a service to the public. It has no other users and no user registration.

2. What Google data the application accesses

The application requests exactly one Google OAuth scope:

  • https://www.googleapis.com/auth/drive.file

This is Google's per-file access scope. It allows the application to create and manage only the files and folders that this application itself creates. The application cannot list, read, modify, share, or delete any other file in the Google Drive account, including files uploaded by the user or by any other application.

The application does not request access to email, contacts, calendar, profile information, or any other Google service.

3. What data is stored, and where

  • Backup data: an encrypted archive of the owner's own local files is written to a folder in the owner's own Google Drive. The archive is encrypted on the owner's machine before upload, so Google Drive only ever stores ciphertext.
  • OAuth credentials: the refresh token issued by Google is stored only on the owner's own machines, inside a file encrypted with the owner's own encryption key. It is never transmitted to any party other than Google itself.
  • Nothing else is stored. There is no database, no server-side storage, no analytics, no telemetry, no crash reporting, and no advertising SDK.

4. Data sharing

No data is shared with, sold to, or disclosed to any third party. The only network destination the application contacts is Google's own API endpoints, in order to upload and manage the owner's backup files. The only data that reaches Google is the application's own backup ciphertext.

5. Data retention and deletion

  • Backup archives remain in the owner's Google Drive until the owner deletes them, either through the Google Drive interface or through the application's pruning settings.
  • The access token held locally can be revoked at any time at myaccount.google.com/permissions, which immediately ends the application's ability to access Google Drive.
  • Deleting the application and its local configuration removes all locally stored credentials.

6. Security

Backups are encrypted client-side before upload, so stored data is unreadable without the owner's encryption key. OAuth credentials are stored only in encrypted files on the owner's machines, readable only by the owner's operating-system user account.

7. Children

The application is a personal tool and is not directed at children. It collects no personal information from anyone.

8. Changes to this policy

If this policy changes, the "Last updated" date above will change accordingly. Because the application has a single user, such changes will be reviewed by that user directly.

9. Contact
